# RIS-парсер — лабораторна робота №14

Удосконалення навчальної програми https://github.com/vkopey/ris-parser.
Збережено Python/PyScript і формат одного основного файлу `index.html`.

## Використання

Відкрийте `index.html` у браузері з доступом до інтернету. PyScript
завантажує Python із зовнішньої CDN. Якщо браузер не підтримує запуск
PyScript із локального файла, опублікуйте файл через GitHub Pages
або використайте локальний вебсервер `python3 -m http.server 8000`
і відкрийте `http://localhost:8000`.

Вставте RIS-текст і натисніть **Перетворити**, або скористайтеся
кнопкою **Вставити приклад**. Кнопка **Копіювати список** копіює результат;
якщо браузер забороняє доступ до буфера, програма пояснює, як скопіювати вручну.

## Виявлені помилки оригіналу

1. Запис `TY  - JOUR\nT1  - Мінімальний запис\nER  -` викликає
   `UnboundLocalError` для `journal`: необов'язкові поля не ініціалізовано.
2. `AU  - Smith, ` викликає `IndexError`: код звертається до першого
   символу порожнього імені.
3. Після збою залишається попередній результат, що вводить в оману.
4. Зріз `[0:-1]` видаляє останній символ значення, коли рядок не має
   кінцевого переведення рядка. Виявлено перевіркою коду.
5. Кілька записів зливаються в один, а поля не розділяються за TY/ER.
6. Не враховано альтернативні теги TI, JF, Y1, діапазон SP/EP,
   багаторядкові значення та нормалізацію DOI.

Перші три проблеми відтворено у браузері на опублікованій початковій програмі.

## Що виправлено

- Безпечні значення за замовчуванням, відсутні дані не спричиняють збою.
- Порожнє ім'я автора, кілька ініціалів, подвійні імена, організації.
- Окремі записи за TY/ER; попередження про відсутні ER, TY і назву.
- Підтримка T1/TI, JO/JF/JA/T2, AU/A1, PY/Y1, VL/IS, SP/EP, PB/CY, DO.
- CRLF, BOM, останній рядок без переведення, рядки продовження.
- DOI у вигляді `https://doi.org/...`, `http://dx.doi.org/...` або `doi:...`.
- Очищення результату перед кожною спробою; зрозумілі повідомлення.
- Український адаптивний інтерфейс, приклад, очищення та копіювання.
- Виведення через `textContent`, тому HTML із RIS не виконується.

Це навчальне бібліографічне форматування. Повна відповідність конкретному
стилю ДСТУ/APA та перевірка DOI у зовнішній базі не заявляються.

## Тестування

```sh
python3 test_parser.py
```

17 автоматичних тестів виконують Python-парсер, витягнутий безпосередньо
з `index.html`, а не його окрему копію. Усі пройдено 02.11.2026.
Повний результат — у `test-results.txt`.
Браузерні тести початкової сторінки описано в `TEST_REPORT.md`.
Виправлений інтерфейс ще потрібно перевірити після публікації у GitHub Pages:
локальний файл у браузері цього середовища відкрити не вдалося.

## Репозиторій для здачі роботи

Форк із виправленою програмою:
https://github.com/lyshchyshyn1508-droid/ris-parser

У гілці `main` розміщено вдосконалений `index.html`, тести та протокол.
Для здачі лабораторної роботи використовуйте посилання на цей форк.

Для перевірки програми онлайн можна ввімкнути GitHub Pages у Settings →
Pages: Deploy from a branch → main → /(root), якщо така конфігурація
доступна у вашому репозиторії. Адресу готової сторінки GitHub покаже
після розгортання. До відповіді викладачеві передусім додайте адресу форка.

Оригінальний код збережено у `original-index.html` для порівняння.

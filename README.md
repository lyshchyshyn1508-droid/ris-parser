# Лабораторна робота №14

**Тема:** Тестування та вдосконалення RIS-парсера.

**Виконав:** Лещишин Богдан Петрович.

Протестував програму та виправив помилки обробки неповних записів і порожніх імен авторів. Додав підтримку кількох RIS-записів, альтернативних тегів, діапазону сторінок та DOI. Оформив інтерфейс українською мовою, додав очищення поля й копіювання результату.

Основний файл — `index.html`. Для роботи потрібно вставити RIS-текст і натиснути «Перетворити».

Перевірив парсер за допомогою 17 тестів. Усі тести пройдено.

```sh
python3 test_parser.py
```

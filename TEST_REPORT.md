| Сценарій | Фактично отримано |
|---|---|
| JOUR; автор «Шевченко, Тарас»; T1; JO; PY; VL; SP; DO; ER | Бібліографічний рядок сформовано |
| TI та автор `Smith, ` із порожнім ім'ям | `IndexError: string index out of range`; попередній результат не очищено |
| JOUR, T1 «Мінімальний запис», ER; без JO/PY/SP/DO | `UnboundLocalError` для `journal`; попередній результат не очищено |

Тести виконано вставленням RIS у поле та натисканням Run у браузері.

в коді. Вони не доводять працездатність кнопок та CDN PyScript у браузері.
Браузерна перевірка виправленої версії після розгортання ще потрібна.
